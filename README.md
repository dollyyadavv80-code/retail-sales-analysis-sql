# retail-sales-analysis-sql

A SQL-based exploratory data analysis (EDA) project on a retail sales dataset, performed using MySQL.

## 📊 Project Overview

This project analyzes retail transaction data to answer key business questions around revenue, customer behavior, product category performance, and profitability — using SQL aggregation, GROUP BY, and HAVING clauses.

## 🗂️ Dataset

- **File:** `retail_sales_analysis_csv`
- **Rows:** 2000 transactions
- **Columns:**

| Column | Description |
|---|---|
| transaction_id | Unique transaction ID |
| sale_date | Date of sale |
| sale_time | Time of sale |
| customer_id | Unique customer ID |
| gender | Customer gender |
| age | Customer age |
| category | Product category |
| quantity | Units sold |
| price_per_unit | Price per unit |
| cogs | Cost of goods sold |
| total_sale | Total transaction revenue |

## ❓ Business Questions Answered

- What is the total revenue, total orders, and average order value?
- How is sales trending month over month?
- What is the total sales generated by male vs. female customers?
- Which categories have total revenue greater than 30,000?
- What is the average price per unit for each category?
- Which category has a profit margin greater than 40%?
- Which customers are one-time buyers?
- Which customers placed more than 20 orders?

## 🛠️ Tech Stack

- **Database:** MySQL
- **Tool:** MySQL Workbench

## 📁 Files

- `retail_sales_analysis_csv` — dataset used for analysis
- `retail_sales_queries.sql` — table creation and all analysis queries

## 🚀 How to Use

1. Create a database in MySQL (e.g. `mydb`)
2. Import `retail_sales_analysis.csv` into a table named `retail_sales`
3. Run `retail_sales_queries.sql` to reproduce the analysis

## 📈 Key Insights

- A small set of loyal customers (20+ orders) contribute significantly to total revenue
- Profit margins vary across categories — some exceed 40%
- Revenue shows a clear month-over-month pattern useful for planning
